# Service Status Tool

THe program handles and checks the status of different services.

## Functions

- List all services with status and response time
- Check the status of a single service
- Add a service
- Change a service's status
- Remove a service

## Files

- 'sst.py' - Starts the program and runs the menu
- 'functions.py' - the programs functions
- 'service.py' - the list of services

## run

python sst.py
